# RotationLab

A crop-rotation decision tool for a farm in India (rice, jowar, bajra, pigeon pea), built for NASA Space Apps 2026 "Field Shift: Adapting Farms with NASA Data". It compares four-year rotations against real weather, shows where land should shift from rice to millets when irrigation water is limited, and says how good the model is. Modeled estimates for planning. Not a guarantee of yield or profit.

## Run
    .venv/bin/pip install streamlit streamlit-folium folium plotly pandas numpy pyyaml scipy anthropic
    .venv/bin/streamlit run app.py

`ROTATIONLAB_MOCK=1` forces the placeholder engine (design review only; a yellow banner is shown). Without a key the plain-English explanation uses a fixed template; set `ANTHROPIC_API_KEY` to have Claude write it from the computed numbers only. Tests: `.venv/bin/pytest`.

## Data provenance
Every number shows a badge: Observed (NASA POWER, ICRISAT, MSP), Modeled, Local input, Assumption, Placeholder. Weather and satellite layers are regional estimates for a grid cell, not measurements on the field. The district is a dev placeholder until set in `config/region.yaml`. See `LIMITATIONS.md` and the in-app source list (links opened and checked in a browser, except ICRISAT, which did not load).
